# ShellBridge

**A macOS-inspired command-line interface for Windows.**

ShellBridge is a Python-based desktop application designed to provide an alternative interface for running supported command-line commands on Windows.

## Features

- macOS-inspired desktop interface
- Built with Python and Tkinter
- Built-in commands and command history
- Directory navigation and drive information
- Calculator command
- ARP table viewing
- Support for selected Windows utilities

## Requirements

- Windows
- Python 3
- Tkinter (usually included with standard Python installations)

## Getting Started

1. Download or clone this repository.
2. Open the ShellBridge Python file in Python IDLE or another Python editor.
3. Run the file.

## Important Notes

ShellBridge is an independent command interface, not a complete replacement for Windows Command Prompt. Some operations depend on Windows configuration, permissions, and system policies.

ShellBridge does not bypass administrator restrictions or organizational security policies.
